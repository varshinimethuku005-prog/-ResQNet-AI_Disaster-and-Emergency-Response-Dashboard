# ResQNet – Disaster and Emergency Response Dashboard

## About the Project

ResQNet is an AI-powered Disaster and Emergency Response Dashboard designed to provide organized information and assistance during emergency situations.

The project aims to bring disaster alerts, relief resources, response information, and emergency assistance into a single user-friendly dashboard.

## Technologies Used

* Python
* Streamlit
* AI / NLP
* Google GenAI
* LangChain
* Geopy
* Folium
* SQLAlchemy
* NLTK
* spaCy
* Transformers
* PyTorch

## Main Features

* Disaster and emergency information dashboard
* Disaster alerts
* Relief resource information
* Emergency response status
* Location-based information
* Interactive maps
* Request assistance functionality
* AI-based assistance and information processing

## Installation

### 1. Create and activate the virtual environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

### 2. Install the required packages

```bash
python -m pip install -r requirements.txt
```

## Running the Application

Start the Streamlit application using:

```bash
streamlit run app.py
```

The application will open in your web browser.

## AI Components

ResQNet is designed to use AI technologies for emergency-related information processing and assistance. The project requirements include Google GenAI, LangChain, NLP libraries, Transformers, and PyTorch.
